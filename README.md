# ZOOUT: site institucional

Site da **ZOOUT**, empresa de soluções digitais: sites, sistemas sob medida,
automação com IA, dados e design estratégico.

🌐 **No ar:** [zoout-site.vercel.app](https://zoout-site.vercel.app)

## O que tem no site
- Página principal com apresentação, soluções, portfólio de projetos, perguntas frequentes e contato
- Página de links (`links.html`) para usar na bio das redes sociais
- Animações que aparecem conforme a pessoa rola a página (`IntersectionObserver`)
- Layout responsivo para celular, tablet e desktop
- Respeita quem prefere menos animação (`prefers-reduced-motion`)
- Ícones para a tela inicial do celular e imagem de pré-visualização para compartilhar (Open Graph)

## Tecnologias
- HTML, CSS e JavaScript puros, sem framework
- Google Fonts (Orbitron)
- Publicado na Vercel

## Como rodar
Não precisa instalar nada. Abra o `index.html` no navegador.
